# ⏰ Stay Productive - Chrome Extension

This Chrome extension helps users stay focused by sending periodic productivity reminders. Every 30 minute, it displays a dynamic notification showing how much time has passed.

## ✨ Features

- ✅ Sends Chrome notifications every `TIME_TO_APPEAR` ms 
- 🕒 Dynamic messages showing time spent (e.g., `Used 30 min`, `Used 1h and 30 min`)
- 🛑 Start and stop functionality via popup interaction
- 🔁 Smart interval management using `setInterval`

## 🧠 Technologies Used

- JavaScript
- TypeScript
- React
- HTML
- CSS
- Chrome Extensions API
